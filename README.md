# AI MVP Scope Checker

A lightweight Chrome extension that helps founders sanity-check whether an AI MVP idea is scoped tightly enough to build in weeks, not months.

Built by [Agitech](https://agitech.group/), an AI-powered full-stack development company that ships production web apps, mobile apps, AI applications, automations, and MVPs with fixed pricing and full code ownership.

## What it checks

- Specific audience
- Clear workflow
- Bounded channel
- Measurable outcome
- Data/input source

## Why this exists

Most AI product builds fail before code because the v1 scope is too vague: undefined users, unclear data sources, no measurable outcome, and too many channels. This extension turns the first sanity check into a 30-second pass before a founder spends money on development.
